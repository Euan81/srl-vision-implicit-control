The folder will contain the SDK first built by Dr. Alexis Devillard (see https://github.com/Aightech/z1_simple) with minor changes to incorporate LabStreamingLayer (LSL) streams from a different 
laptop (MacBook) to control end-effector velocity, remove unnecessary joint limits and edit speed limits, that would be necessary in a backpack-mounted supernumerary limb. The LSL component 
was edited to incorporate a seventh stream to open and close the gripper at fixed speed, while the first six control x, y ,z, pitch, roll and yaw velocities, respectively.
